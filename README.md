# Timesheet System

ระบบลงเวลางานส่วนตัวบนเว็บ พร้อม Export Excel

## Features
- 📝 ลงเวลางานรายวัน (Date, Feature, Activity, Hours, Minutes, Note)
- 📊 แสดงรายการทั้งหมดในรูปแบบตาราง
- 📤 Export ข้อมูลเป็น Excel (.xlsx)
- ⚙️ ตั้งค่าข้อมูลส่วนตัวและ Preset values
- 🔄 คำนวณวันทำงานอัตโนมัติ

## Tech Stack
- React + Tailwind CSS + Vite
- Node.js + Express + SQLite3
